# Clinical NER Annotation Tool

## Overview

The Clinical NER Annotation Tool is a Human-in-the-Loop annotation platform developed for extracting and reviewing named entities from clinical text. It combines multiple clinical NER models with an interactive interface that allows users to compare model outputs, edit annotations, add new entities manually, and export the final results.

The goal of the application is to make the annotation process faster while still allowing users to validate and refine the automatically detected entities.

---

## Features

- Upload clinical documents in **TXT** and **PDF** format
- Annotate text using five different NER approaches:
  - Ensemble Transformer
  - scispaCy + Regex
  - Qwen 2.5 (LLM)
  - BioBERT + MACCROBAT
  - ClinicalBERT + MACCROBAT
- Highlight detected entities directly in the document
- View extracted entities in a side panel
- Add manual annotations by selecting text
- Edit entity labels and confidence scores
- Delete annotations
- Export annotations as JSON
- Display basic annotation statistics such as:
  - Number of supported models
  - Number of detected entities
  - Processing time

## Running the Application

### Backend

```bash
cd UI/backend
uvicorn main:app --reload
```

### Frontend

```bash
cd UI/frontend
npm install
npm run dev
```

Once both servers are running:

- Frontend: `http://localhost:5173`
- Backend: `http://127.0.0.1:8000`

## Purpose

This application was developed as part of a Clinical Named Entity Recognition (NER) project. It provides an easy-to-use interface for reviewing, correcting, and managing clinical annotations generated by different NER models, making it useful for dataset creation, evaluation, and comparison of multiple approaches.
